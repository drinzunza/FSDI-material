SDGKU FSDITopic 120.3
A minimal pipeline

GitHub Actions: test on every push

name: CI
on: [push]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
      - run: pip install -r requirements.txt
      - run: python manage.py test
  • Lives at .github/workflows/ci.yml in your repo.
  • React variant: setup-node → npm ci → npm test → npm run build.
  • The green check on the PR is your merge gate.

Scaling basics

Vertical vs horizontal scaling

Vertical — a bigger server

More CPU / RAM on one machine. Simple, no code changes — but it has a ceiling and is a single point of failure.

Horizontal — more servers

Copies of the app behind a load balancer. Needs a stateless app and a shared database/sessions — scales much further.

Capstone rule of thumb: a small PaaS instance is plenty. Know the difference for interviews.
